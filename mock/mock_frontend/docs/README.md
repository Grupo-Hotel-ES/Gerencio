# Página de MOCK para simulação dos apps de pedidos.

## Campos:
- Dropdown para selecionar qual app será simulado (Ifood, 99 food, uber eats, rappi e keeta).
- Nome do cliente.
- Endereço para entrega.
- Cardápio com produtos (busca do serviço de produtos).
- Tab de navigation com página de pedido e de carrinho.
